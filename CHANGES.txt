追加機能: build.py - Pythonベースのインタラクティブビルドスクリプト
===============================================================================
ファイル: build.py (新規作成)

【概要】
build.shをベースにしたPythonスクリプトで、以下の機能を追加:
1. インタラクティブなbootmode選択メニュー
2. rootパスワードの入力機能（空を受け付けない）
3. パスワード確認機能
4. Jinja2テンプレートからkickstartファイルを動的生成

【使用方法】
# ./build.py

【主な機能】
- bootmode選択: メニュー形式で1-4を選択
  1) uefi      - UEFI boot (CLI only)
  2) mbr       - MBR/BIOS boot (CLI only)
  3) uefi_gui  - UEFI boot with GUI (XFCE + RDP)
  4) mbr_gui   - MBR/BIOS boot with GUI (XFCE + RDP)

- rootパスワード設定:
  * 入力時は非表示（getpass使用）
  * 空パスワードは拒否
  * 確認入力で一致チェック
  * テンプレートに自動適用

【技術的詳細】
- Jinja2テンプレートエンジンを使用
- template.ks.j2から各パターンのkickstartを動的生成
- 一時ファイルを作成し、ビルド完了後に自動削除
- 既存の4つのksファイルは変更しない（build.shとの互換性維持）

【build.shとの違い】
- インタラクティブなUI
- テンプレートベースの生成（メンテナンス性向上）
- パスワードのカスタマイズが簡単
- エラーハンドリングの強化
- より詳細な進捗表示

===============================================================================
追加機能: template.ks.j2 - Kickstart統合テンプレート
===============================================================================
ファイル: kickstart/template.ks.j2 (新規作成)

【概要】
既存の4つのkickstartファイル（uefi_main.ks, mbr_main.ks, uefi_gui.ks,
mbr_gui.ks）を1つのテンプレートに統合。

【統合による改善点】
1. メンテナンス性: 1ファイル修正で全パターンに反映
2. 一貫性: 共通部分が完全に同一になる
3. DRY原則: コードの重複を排除

【テンプレート変数】
- uefi: UEFI/MBRの切り替え（bootloader、パーティション、パッケージ）
- gui: GUI/CLIの切り替え（デスクトップ環境、RDP設定）
- root_password: rootパスワード

【GUIでの変更点】
- firefoxとchromiumの両方をインストール（完全に共通化）
- uefi_guiとmbr_guiで完全に同じGUI環境

【後方互換性】
- 既存の4つのksファイルは保持（build.shで使用）
- build.pyはテンプレートを使用
- 将来的に既存ファイルは段階的に廃止予定

【依存関係】
- Jinja2ライブラリが必要
  インストール方法: dnf install python3-jinja2
              または pip3 install jinja2
