# default-remove-packages

[← 一覧に戻る](README.md)

## 概要

イメージ縮小のため不要なパッケージ群を削除します。
ワイヤレスファームウェアパッケージ (`iwl*-firmware`) を除外します。

## メタ情報

| 項目 | 値 |
|------|-----|
| 種別 | 常時適用 (`check = false`) |
| 適用順序 | 5 |
| 対応OS | 全OS |

## 除外パッケージ

| パッケージ | 説明 |
|-----------|------|
| `-iwl*-firmware` | Intel ワイヤレスアダプター用ファームウェア |
