# add-xfce-gui-support

[← 一覧に戻る](README.md)

## 概要

XFCE デスクトップ環境と XRDP をインストールします。
RDP (ポート 3389) 経由でリモートデスクトップ接続が可能になります。

## メタ情報

| 項目 | 値 |
|------|-----|
| 種別 | 選択式 (`check = true`) |
| デフォルト | — (未選択) |
| 適用順序 | 50 |
| 対応OS | Rocky Linux 8, 9 |
| 依存プラグイン | — |

## 設定内容

| 設定 | 内容 |
|------|------|
| リポジトリ | EPEL を有効化 |
| デスクトップ | XFCE グループをインストール |
| 追加パッケージ | `langpacks-ja`、`glibc-langpack-ja`、`ibus-mozc`、`firefox`、`chromium`、`xrdp` |
| 起動設定 | グラフィカルターゲットをデフォルトに設定 |
| XRDP | 自動起動を有効化、ポート 3389 を開放 |
| 入力メソッド | IBus の環境変数を `.bashrc` に設定 |

> **Note:** RDP と物理グラフィカル画面から同一ユーザーで同時ログインすることはできません。
